# Book Reading List Application

A responsive client-side web application developed in **Lecture 11 (Vibe Coding with Bolt AI)** and deployed using Vercel.

## Live Deployment
* **Live Application URL:** https://reading-list-app-phi.vercel.app *(or your active deployment URL)*

## Overview
This application enables students to manage reading materials, set reading priorities, track completion states, and prevent redundant entries with real-time UI feedback.

## Features
* **Reading Status Tracking:** Effortlessly transition items between *Want to Read*, *Reading*, and *Finished*.
* **Status Filtering:** Dynamic tabs to filter books according to their current progress state.
* **Metric Counters:** Real-time summary dashboard displaying total, in-progress, and finished counts.
* **Duplicate Prevention:** Case-insensitive duplicate detection eliminating redundant additions.
* **Input Validation:** 60-character maximum title enforcement with helpful validation messages.
* **Persistent Storage:** Browser `localStorage` integration preserving reading records across sessions.

## Technologies Used
* **HTML5:** Semantic architecture
* **CSS3:** Flexbox, Grid, custom styling, mobile responsiveness
* **JavaScript (ES6):** LocalStorage API, state manipulation, event delegation
* **Vercel:** Cloud hosting and deployment
